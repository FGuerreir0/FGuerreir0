### 🎼 Al Coda  
**Founder & Creator**

🔗 https://alcoda.netlify.app/

Al Coda is an **all-in-one management platform for orchestras, bands, and choirs**, designed to simplify the organization of musical ensembles.

The platform helps music groups stay organized by managing rehearsals, attendance, and administrative tasks in one place.

**Key features**
- Rehearsal scheduling and planning
- Attendance management
- Fuel allowance automation
- Communication and coordination tools for ensembles

*"Your orchestra, band, or choir works better here."*

**Real-time collaborative pixel art platform**

🔗 https://github.com/FGuerreir0/dotdrop  

A multiplayer pixel canvas inspired by r/place where users collaborate in real time to create artwork. Built with WebSockets and Supabase for live synchronization and scalable interaction.

**Key features**
- Real-time drawing with multiple users
- WebSocket-based synchronization
- Persistent canvas storage
- Community collaboration mechanics
